🎓 KEY CONCEPTS:

SSH (Secure Shell):
└─ How you access the server remotely
└─ Command: ssh username@server-ip

PM2 (Process Manager):
└─ Keeps your Node.js backend running
└─ Restarts if it crashes
└─ Starts on server boot

Nginx (Web Server):
└─ Serves your React frontend
└─ Routes /api calls to Node.js
└─ Handles HTTPS/SSL

MySQL Database:
└─ Replaces TiDB
└─ Runs on college server
└─ Stores all application data

Cloudinary:
└─ External service for file storage
└─ Can keep as-is
└─ Handles image/resume uploads
